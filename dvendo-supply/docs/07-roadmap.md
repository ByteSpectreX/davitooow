# Build roadmap

| Phase | Deliverable | Exit evidence |
| --- | --- | --- |
| 0 — foundation | Portable code, UI preview, guides, contracts, imported research | Build, offline tests, link/provenance verification and Cloudflare dry run |
| 1 — app identity | Authenticated supplier/manager membership and assignment scope | Cross-workspace, cross-manager, transfer and export denial tests |
| 2 — persistence | SIM registration, versioned promo plans, audit and schedule records | Database migration tests, restart persistence and ownership tests |
| 3 — read integration | Supplier connection/balance; recipient validation and eligible catalog | Separately authorized dated sanitized query evidence |
| 4 — controlled fulfillment | Durable attempts and one reviewed supplier-funded recipient purchase | Separate order, debit and recipient-delivery evidence; no inference from a reference alone |
| 5 — renewals | Supplier limits, scheduling, forecast, funding holds and reconciliation | Duplicate alarm, concurrent spend, restart, timeout and expiry/overlap tests |
| 6 — production | Scoped staging pilot, deployment/access review, recovery and operations guide | Verified complete loop for a small authorized portfolio |

Phase 0 is a starter, not a production release. Each next phase builds upon evidence from the preceding one. The owner has established the direction of automatic renewals; exact budget/timing decisions and authorization for individual provider experiments remain separate.
